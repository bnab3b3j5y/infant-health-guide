# 先天性代谢缺陷的孩子如何护理？每个患儿家庭都要了解

> 更新时间：2026-09-11 (UTC+8)

一、初次面诊

小小王出生一周岁生日那天，全家带她去妇幼保健院做了个检查，本来以为是例行检查不会有什么问题，但是却收到了电话通知，说小小王的苯丙氨酸浓度比同龄孩子高很多，当地妇幼保健院初步怀疑是苯丙酮尿症，但还需要做进一步检查确诊，所以医生建议他们一家尽快到我院做深入检查和后续治疗。

这也就是我第一次见到他们一家，是我和他们一家缘分的开始。其实，在他们抱着小小王进入诊室的时候，我第一反应就是孩子得了苯丙酮尿症，因为孩子身上散发着明显的鼠尿味，这个味道虽不好闻，却是该病的显著特点，倒是佐以诊断了。

为了进一步检查，还需要完善酪氨酸、生物喋呤、新喋呤、苯丙氨酸色谱分析等检查，发现宝宝的苯丙氨酸值一直高居50mg/dl左右，而临床上对于2mg/dl的苯丙氨酸值患者会诊断为苯丙酮尿症，看来小小王的情况不太乐观啊！

二、治疗经过

在确诊后，这对新手爸妈看起来很低落，我在提出苯丙酮尿症可以用药的时候，遭到了孩子妈妈的强烈反对，这个母亲泪眼婆娑地恳求我，说孩子真的太小了，不能受得了药物的，万一对身体造成伤害怎么办？我回答：您别急，我只是说这个病可以用药，我也是考虑到小小王才几个月这一点，我认为可以用饮食疗法，即低苯丙氨酸饮食。然后我为他们详细介绍了这个饮食的具体内容，他们说回家后一定给宝宝坚持这个饮食治疗！

先给患儿喂食特制的低苯丙氨酸奶粉，由于限制苯丙氨酸摄入的特制食品价贵，所以待血浓度降到正常后，逐步添加辅食如母乳，因母乳中苯丙氨酸含量低；到幼儿期添加辅食时应以淀粉类、蔬菜、水果等低蛋白食物为主还可添加牛奶、粥、面包等；由于苯丙氨酸是合成蛋白质的必需氨基酸，过量限制苯丙氨酸摄入会影响大脑的正常发育，完全缺乏时亦可导致神经系统损害，治疗时应定期检测血中苯丙氨酸的浓度；饮食控制持续到16岁。终身要通过低蛋白饮食来进行治疗。

三、治疗效果

我嘱咐他们，要谨记进行复检。随访至今已有五年时间，小小王坚持低苯丙酮尿饮食，苯丙氨酸的浓度一直控制在正常水平。

四、注意事项

对于苯丙酮尿症，最佳的治疗方法就是控制饮食。平时吃的肉、蛋、奶以及面食都要避而远之，最起码也要控制摄入量。除了在饮食方面注意之外，还需要定期对孩子进行抽血检验，查看苯丙氨酸浓度，来调整饮食比例。

五、个人感悟

在先天代谢缺陷病中，苯丙酮尿症是属于少数能够治疗的较轻的病症。虽然孩子患病全家担惊受怕，但换个角度想，及时发现早期治疗，未来也能正常生长发育，未尝不是不幸中的万幸！
